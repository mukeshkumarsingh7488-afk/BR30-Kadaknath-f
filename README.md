# 🐔 BR30 Kadaknath Farms

> A modern, responsive e-commerce frontend for **BR30 Kadaknath Farms**, built to showcase and sell Kadaknath poultry products through a clean, trustworthy, and user-friendly shopping experience.

---

## 📌 Overview

**BR30 Kadaknath Farms** is a modern e-commerce web application designed for a Kadaknath poultry farm.

The frontend provides customers with an easy way to:

- Explore Kadaknath products
- View detailed product information
- Add products to cart
- Place orders
- Track orders
- Manage their account
- View order history
- Contact the farm
- Learn about the farm and its farming practices

The application also includes a dedicated **Admin Dashboard UI** for managing products, orders, customers, and farm operations.

The project focuses on a clean interface, responsive design, simple navigation, and a professional agricultural e-commerce experience.

# ⚙️ Installation

## 1. Clone or download the project

Place the frontend project on your local machine.

## 2. Open the frontend directory

```bash
cd frontend
```

## 3. Install dependencies

```bash
npm install
```

## 4. Configure environment variables

Create a `.env` file in the frontend root if required by the application.

Example:

```env
VITE_API_URL=your_api_url_here
```

> Do not commit `.env` files containing private credentials or secrets.

# 🔐 Security

The frontend follows several security-focused practices:

- Sensitive environment files are excluded from Git
- Authentication-related pages are separated from public pages
- Admin routes use dedicated route protection
- Customer-specific routes are separated from public routes
- Protected application functionality should always be enforced by the server-side application
- Sensitive credentials should never be hard-coded into frontend source files

> `robots.txt` is only a crawler instruction and should never be considered an access-control or security mechanism.
